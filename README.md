# 🌤️ Advanced Weather Forecast

A sleek, responsive, and feature-rich weather forecast app built using **HTML**, **CSS**, and **JavaScript**. It fetches real-time weather data using the [OpenWeatherMap API](https://openweathermap.org/api) and provides a beautiful user experience with location detection, icons, dark mode, and a 5-day forecast.

---

## 🚀 Features

- 📍 **Auto-Detect Location**: Automatically fetches the user's current location.
- 🔍 **City Search**: Manually search for any city’s weather.
- 🌡 **Current Weather**: Displays temperature, condition, humidity, wind speed, and more.
- 🖼️ **Weather Icons**: Dynamic weather icons based on real-time conditions.
- 📆 **5-Day Forecast**: Get a concise view of upcoming weather.
- 🌑 **Dark Mode**: Toggle dark/light theme for better UX.
- 📱 **Responsive Design**: Optimized for mobile, tablet, and desktop.
